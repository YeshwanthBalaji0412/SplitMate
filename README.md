# SplitSmart — Explainable Expense Splitting Engine

## 🚀 Overview
SplitSmart is a modern expense-splitting application designed to solve real-world problems that existing tools struggle with.

Unlike traditional apps, SplitSmart supports:
- item-level bill splitting
- tax, tip, and fee allocation
- regional charge differences
- explainable calculations
- fair and transparent settlements

## 🎯 Problem
Current expense-sharing apps do not handle:
- multiple tax types
- delivery/service/platform fees
- selective participation in charges
- item-level consumption differences
- transparent breakdown of final amounts

## 💡 Solution
SplitSmart introduces a **rule-based, explainable split engine** that:
- models real-world bills accurately
- allows flexible allocation rules
- provides full breakdown per user
- ensures fair and auditable settlements
